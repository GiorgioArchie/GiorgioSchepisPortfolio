# Giorgio Schepis — Portfolio

A responsive React + TypeScript portfolio built with Vite.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.
4. Run `npm run build` to verify a production build.

## Personalize before sharing

- Keep `src/data.ts` current; the hero’s **Download resume** button generates a PDF from the portfolio details when clicked.
- The headshot in the workspace root is used by the hero portrait. Replace it with a professional, well-cropped image if desired.
- Update the page title and description in `index.html`.
- Review your project, contact, and education details before deployment.
